NASA KrishiBondhu v1.3.5 - Pre-flight + Claude fallback (একবারেই deploy)

নতুন: https://<আপনার-render>.onrender.com/api/diagnostics
এক URL এ সব পরীক্ষা: Earthdata env, SQLite, AppEEARS login + MODIS/ECOSTRESS layer, Claude key + CHAT_MODEL (live ping)।
APK build করার আগে এটি খুলুন; overallOk=true না হলে আগে সেটি ঠিক করুন।

Render > Environment এ নাম হুবহু এই হতে হবে
  NASA_EARTHDATA_USERNAME, NASA_EARTHDATA_PASSWORD, ANTHROPIC_API_KEY
  CHAT_MODEL (ঐচ্ছিক; না দিলে claude-sonnet-5-5। পুরোনো/ভুল model লিখে রাখলে মুছে দিন)

কী কী শক্ত করা হয়েছে
1. Claude ভুল pathway id দিলে ঠিক করে নেয় (আগে 502); তালিকা বেশি হলে ছাঁটে; একবার retry।
2. Claude সম্পূর্ণ ব্যর্থ হলে (key/credit/model/নেটওয়ার্ক) Advice ট্যাব খালি থাকে না: স্পষ্ট লেবেলসহ "নিয়মভিত্তিক সারাংশ (AI অনুপস্থিত)" আসে। নতুন কোনো তথ্য/ডোজ যোগ হয় না।
3. Rate limit: Render proxy এর কারণে সব ব্যবহারকারী একই IP ধরা পড়ত (ঘণ্টায় ৪০ মোট)। এখন X-Forwarded-For ধরা হয় এবং সীমা ১৫০/ঘণ্টা।
4. "সার্ভার ও NASA অ্যাক্সেস যাচাই" বাটন এখন Claude key আসলেই কাজ করছে কিনা দেখায় (শুধু আছে কিনা নয়)।
5. আগের সব ফিক্স (GWET মাটির আর্দ্রতা, MODIS good+marginal, task resume, error বক্স) অন্তর্ভুক্ত।

Deploy ক্রম
  1) backend/ push -> Render redeploy 2) /api/diagnostics খুলে সব OK দেখুন 3) APK build (versionCode 9) -> install
সীমাবদ্ধতা: live NASA/Render/Claude এর বিরুদ্ধে চালানো হয়নি; Java এর শুধু syntax ও symbol পরীক্ষা (Android SDK ছাড়া পূর্ণ compile নয়)।
